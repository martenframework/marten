_October 10, 2026._

## Bug fixes

* Fix routes nested under a sub-map mounted on a [translated path](../../i18n/localized-routes.md) reversing to the default-locale path. Reversed URLs for such routes could not be resolved when a non-default locale was active.
* Fix `sum` annotations raising an error on PostgreSQL when targeting big integer or decimal fields.
* Fix request data parsing for malformed `multipart/form-data` requests. Missing boundaries (or empty bodies) now yield empty data, while other malformed multipart payloads raise a bad request (`Marten::HTTP::Errors::InvalidRequestParameters`) instead of an unhandled server error.
* Fix the [`serve`](../../development/reference/management-commands.md#serve) management command interleaving the server's "Shutting down" message with the compilation spinner when reloading after source file changes.
