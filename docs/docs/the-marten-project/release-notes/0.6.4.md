## Bug fixes

* Fix prefetched relations not being preserved through chained operations on query sets for reverse many-to-one and many-to-many relations.
* Fix possible cache key collisions in the [`cache`](../../templates/reference/tags.md#cache) template tag when distinct "vary on" values concatenate to the same string.
