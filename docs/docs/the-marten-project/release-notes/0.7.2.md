_Under development._

## Bug fixes

* Fix the debug logger raising unexpectedly when request data cannot be parsed and [debug mode](../../development/reference/settings.md#debug) is enabled.
* Fix request data parsing for malformed `application/json` bodies. A body that is not valid JSON now raises a bad request (`Marten::HTTP::Errors::InvalidRequestParameters`) instead of `JSON::ParseException`.
* Fix [`#join`](../../models-and-databases/queries.md#pre-selecting-relations-with-joins) and [`#prefetch`](../../models-and-databases/queries.md#pre-fetching-relations) having no effect on reverse one-to-one relations for records without a related object, which resulted in a query on every access. These methods now record that absence, which has a few consequences: a related record created afterwards is only visible after calling [`#reload`](pathname:///api/dev/Marten/DB/Model/Persistence.html#reload-instance-method), a related record excluded by a custom [`#prefetch`](../../models-and-databases/reference/query-set.md#prefetch) query set is considered absent, and such a query set is ignored if the relation was already loaded by [`#join`](../../models-and-databases/reference/query-set.md#join), like for other single-valued relations.
